# Ejercicios de Algoritmia en PSeInt

SEMANA 1 algoritmos desarrollados en PSeInt.

1. **`Preparar_Cafe.psc`**  
   * **Lógica:** Usa condicionales simples (`Si`) para evaluar las respuestas del usuario y decidir si agrega ingredientes extra al café.

2. **`Promedio_Gastos_Semanales.psc`**  
   * **Lógica:** Aplica una estructura secuencial que suma cuatro entradas numéricas y divide el total entre 4 para obtener el promedio.

3. **`Consumo_Electrico_Mensual.psc`**  
   * **Lógica:** Realiza cálculos aritméticos lineales para convertir el consumo diario de vatios a kilovatios-hora mensuales y calcular su costo.

4. **`Nivel_Internet.psc`**  
   * **Lógica:** Implementa condicionales anidados (`Si-SiNo`) para clasificar la velocidad de conexión dentro de distintos rangos numéricos.

5. **`Hamburguesas_Bien_Buenas.psc`**  
   * **Lógica:** Valida mediante un condicional que la cantidad de hamburguesas sea mayor a cero antes de dividir el peso total de la carne para evitar errores.

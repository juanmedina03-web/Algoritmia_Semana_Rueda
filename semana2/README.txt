# Ejercicios de Algoritmos de Decisión en PSeInt

Colección de 5 algoritmos desarrollados en PSeInt utilizando estructuras condicionales.

1. **`MontañaRusa.psc`**  
   * **Lógica:** Usa el operador lógico `Y` para validar que se cumplan dos condiciones simultáneas (estatura mínima y ausencia de mareos) antes de permitir el ingreso.

2. **`ValidarLicencia.psc`**  
   * **Lógica:** Aplica las Leyes de De Morgan negando la condición de éxito mediante el operador `O` para detectar primero si el usuario no cumple los requisitos.

3. **`ParqueaderoSimple.psc`**  
   * **Lógica:** Evalúa con condicionales anidados si se descuentan horas gratis por factura y luego decide entre cobrar por hora o aplicar una tarifa plana.

4. **`EsBisiesto.psc`**  
   * **Lógica:** Calcula los residuos de dividir el año entre 4, 100 y 400 para determinar mediante operadores lógicos si el año tiene 366 días.

5. **`ControlCupos.psc`**  
   * **Lógica:** Emplea condicionales anidados en cascada para descartar números negativos y clasificar los cupos disponibles en tres estados (Rojo, Amarillo y Verde).
